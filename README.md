# Digital Asset Protection System

This is the project scaffold encompassing the structural layout for the digital asset protection system.

## Backend
Python + FastAPI. Contains routers, services, utilities, and Pydantic schema structure.
Run standard FastAPI using `uvicorn main:app --reload` from `backend` folder.

## Frontend
Scaffolded with Vite and React.
```bash
cd frontend
npm install
npm run dev
```
